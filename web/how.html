Build log · 8–9 October 2026

A ZX Spectrum, built overnight

At 21:32 the owner asked for a faithful ZX Spectrum to play Saboteur on. At 08:59 the next morning it was live on the web, accurate to the clock cycle and checked against what real hardware shows. Claude Code planned it, wrote the contracts between its parts, and ran 23 agents to build, review, criticise and fix it.

Let's build a faithful replica of ZX Spectrum as a faithful software emulator. I want to be able to play Saboteur and other games from my youth on it. Amaze me

Method

How it was organised

  1. A contract before any code

    The orchestrator laid out nine crates, the Z80's bus, the timings, the keyboard matrix and the picture's format in one document, so that agents who never meet could build parts that fit.

  2. One part per agent, tested alone

    The Z80, the sound chip, tapes, snapshots and the page were built at once, each in its own directory with its own test layer, so no one waited on anyone's half-finished code.

  3. Held to other people's tests

    Every part was judged by suites written to catch emulators out: FUSE's, SingleStepTests, ZEXALL, Patrik Rak's z80test, and captures from real machines that a researcher gathered while the parts were being built.

  4. A reviewer behind every builder

    Each builder was followed by an adversarial reviewer, told to assume there were bugs, to check every claim against its source, and to fix what it found.

  5. Played, looked at, and taken apart

    With the real core in the page, three critics went over it, as a player, a designer and an engineer, without touching it. A fixer applied what they found, and a verifier rebuilt everything from scratch.

  6. The orchestrator checked the checkers

    Between phases it ran every test, looked at every screenshot, reproduced the compiler bug a reviewer reported, removed a personal address an agent had put in a request header, and committed.

Review

What the reviewers caught

78 findings across nine reviews, nearly all fixed before anyone opened the page. A few were declined, each with its reason written down.

Findings by review

Machine reviewer

A miscompilation in rustc 1.98.1

Safe Rust filling the contention table read past an eight-byte array at -O2, slipping stack bytes into the timing. The orchestrator reproduced it in 40 lines; a release-build test now guards it.

Z80 reviewer

A test that could not fail

Breaking the CPU on purpose showed the FUSE comparator accepted a wrong address on internal cycles, the very cycles a Spectrum's contention depends on.

Machine reviewer

Instant loading that lied

The trap that loads tape blocks at once left registers the real ROM never leaves. It is now checked against the ROM itself reading the tape's edges.

Tape reviewer

A tape that kept talking

With the deck stopped, the EAR line could stay high, which breaks games that read the keyboard through the same port.

Engineer critic

A joystick lost at power-on

After every reset the Kempston port read the floating bus, which a game takes as all four directions and fire held at once.
