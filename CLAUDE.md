# zx-spectrum

This project is looked after by nerd, a command-line tool on this machine that does the chores every project
here shares: its tests, deploying it to Google Cloud, its address and secrets, and the watches, phones and
emulators an app is tried on. Run `nerd guide` before anything else: it says how projects are built here, and
what nerd does for them.

What the project is for is in IDEA.md, in the words of whoever asked for it. Start there.
